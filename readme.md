# Static JSON Backend

This repository provides a **generic static JSON backend** hosted on Vercel.  
It is intended to serve read-only JSON data that can be consumed by mobile apps, web apps, or other services as a lightweight alternative to a traditional backend.

---

## Purpose

The goal of this project is to:

- Host static JSON files as public HTTP endpoints
- Simulate a simple backend for early-stage projects, prototypes, or educational apps
- Keep data versioned and organized by project
- Avoid server, database, or authentication complexity
